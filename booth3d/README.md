# Name City · 名前の街

The 3D booth (flutter_scene), and the talk told in it.

Present the talk offline, from the repository's root (builds and installs the
Mac app the first time, then just opens it):

```bash
bash booth3d/tool/talk.sh            # the talk, from the title
bash booth3d/tool/talk.sh 5          # from section 05
bash booth3d/tool/talk.sh --voice    # told by itself in the recorded voice
bash booth3d/tool/talk.sh --rebuild  # build and install again first
```

More in the repository's [README](../README.md).
